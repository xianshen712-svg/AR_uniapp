# 需求总结（精简版）
## 项目基础
基于 **UniApp Vue2 项目，打包编译为微信小程序**，接入微信官方 `xr-frame` 能力，依托开源 `xr-frame-demo` 官方示例做功能复刻。

## 核心需求
1. 项目首页增加一个 **XR-Frame AR 入口按钮**；
2. 点击按钮进入**XR能力卡片列表页**，把 xr-frame 不同核心能力做成**独立卡片**展示；
3. 每张卡片对应一种官方能力（基础3D、AR平面、AR图片Marker、人脸/手势、glTF模型、物理引擎、视频纹理等）；
4. **点击对应卡片 → 进入独立XR场景页**，单独演示该能力；
5. 场景页带返回按钮，可退回卡片列表页；s
6. 整体按 **UniApp 规范开发**，适配微信小程序，可直接配置、复制代码落地；
7. 输出一份完整 MD 方案，包含配置、页面代码、分天开发计划、部署注意事项。

## 页面结构
首页 → XR入口按钮 → 能力卡片列表页 → 点击卡片 → 对应XR场景演示页 → 可返回列表。

## 技术约束
- 技术栈：UniApp + Vue2 + 微信小程序 xr-frame
- 格式全部遵循 UniApp 语法，可直接运行
- 复用 xr-frame-demo 各类能力，做卡片化分类、场景隔离演示
